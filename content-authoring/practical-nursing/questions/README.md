# Practical Nursing Topic Question Packs

Status: ACTIVE AUTHORING

## Completion requirement

Every qualifying practical-nursing lesson topic must have at least **60 high-quality questions for each applicable exam and country pathway** before that pathway is complete.

## Required question contract

Each question must include or resolve to:

- stable deterministic question ID
- country ID/label
- exam ID/label and test-plan version where applicable
- practical-nursing tier/role ID
- exact topic ID matching the lesson topic
- renderable question type
- stem and plausible distractors
- stable answer contract
- correct-answer rationale
- per-option distractor rationales for option-based items
- unit-system/localization handling
- difficulty/cognitive intent where supported by the serving schema
- clinical pattern/competency metadata where supported

## Reuse policy

Reuse is allowed when the clinical truth is genuinely jurisdiction-independent. Reuse is **not** a metadata-only excuse for jurisdiction-sensitive content.

Safe reuse candidates include:
- core anatomy/physiology
- pathophysiology
- common recognition patterns
- universal emergency ABC principles
- basic medication mechanisms where drug availability/use is shared

Must be localized:
- role/scope/delegation
- legal and regulatory requirements
- public-health reporting/isolation rules
- screening schedules
- drug availability, formularies, prescribing/administration authority
- units and spelling
- exam blueprint/client-needs/competency mapping
- country-specific terminology and escalation pathways

Every reused pack receives new country/exam-specific stable IDs. If a stem contains a role or jurisdiction assumption, that stem must be rewritten before reuse.

## Quality rules

1. Test judgment and application, not trivia-only recall.
2. Distractors must be clinically plausible and distinct.
3. Do not reveal the answer through grammar, length, absolute wording, or duplicated rationale language.
4. Rationales explain why the correct answer is safest/best and why each distractor is inferior or unsafe.
5. Question sets should vary assessment, prioritization, medication safety, diagnostics/monitoring, teaching, complications, and escalation.
6. Difficulty should remain appropriate to the served practical-nursing role; do not import RN/NP independent-management assumptions.
7. Numeric values must use the served unit system and remain internally consistent.
8. Country/exam reuse must preserve clinical truth while localizing scope, terminology, and blueprint.
